 🎨 Advanced Paint App - DEMO 

A modern and interactive **drawing application** built using **HTML5 Canvas**, **JavaScript**, and **CSS**. This project allows users to draw freely, use various shapes, brush tools, erasers, and choose custom colors — making it a fun and intuitive painting experience in the browser.

**✨ Features**

- ✅ **Draw** using a freehand brush
- ⬛ **Shape tools**: Rectangle, Circle, Triangle
- 🧼 **Eraser** tool
- 🎨 **Custom color picker** (black, white, red, green, blue)
- 🔘 **Brush size** adjustment with slider
- 🪄 **Fill mode** (Color-filling shapes)
- 🗑️ **Clear canvas**
- 💾 **Save drawing** as an image

## 🛠️ Tech Stack

- **HTML5** – Canvas element
- **CSS3** – Styling and layout
- **Vanilla JavaScript** – App logic and interactivity
